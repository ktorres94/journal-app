# Journal App – Final Project

A simple Android journaling app built using Java, XML, and SQLite. It allows users to write, save, view, edit, and delete journal entries with a clean and user-friendly interface.

## Project Description
A basic Android journaling app that allows users to write and save personal entries. The goal is to offer a simple, easy-to-use interface for taking daily notes or reflections.

## Problem Addressing
People who want to keep a journal often struggle with remembering to write, losing their place, or not having a notebook with them. This app solves that by making journaling available on any Android phone.

## Platform
The app was developed using Android Studio (Meerkat) for the Android operating system. It is built natively using Java and XML, with local data storage managed by SQLite.

## Frontend / Backend Support
- **Frontend**: XML layouts created in Android Studio. Includes Home, New Entry, and View/Edit Entry screens.
- **Backend**: Uses a local SQLite database to store entries, accessed via SQLiteOpenHelper.

## Functionality
- Create and save new journal entries
- View a list of stored entries
- Edit existing entries
- Delete entries with confirmation prompt
- Supports dark mode
- Local data persistence using SQLite

## Wireframes
The app includes the following basic screens:
1. Home screen with options to create or view entries
2. Screen to add or edit a journal entry
3. Screen to view/delete existing entries

Wireframes were initially sketched and later recreated using Justinmind.
